# CONTRIBUTING · Как вносить вклад в OS-FORGE

Спасибо за интерес к проекту. OS-FORGE — самодостаточный батник: карта среды →
решение → сеть → сборка актуальной ОС → готовый ISO с манифестом. Чтобы вклад
укладывался в эту модель, соблюдайте простой порядок.

## Философия проекта (коротко)

1. **Карта = территория.** Каждое утверждение (что батник делает, какие источники
   использует) должно совпадать с реальностью. Не пишите «работает», если не
   запускали; помечайте гипотезы как гипотезы.
2. **Ноль прав администратора.** Скрипт обязан работать из пользовательской
   сессии. Изменения, требующие elevation, отвергаются.
3. **Манифесты вместо обещаний.** Всё, что скачивается и собирается, фиксируется
   в манифесте с хешами. Новые источники — только официальные URL с проверкой.

## Как предложить изменение

1. Открой issue по шаблону (дефект или предложение) — опиши наблюдение, а не вывод:
   что делал, что ожидал, что получилось, версия ОС и батника.
2. Для кода: форк → ветка `fix/<коротко>` или `feature/<коротко>` → правки.
3. Pull Request по шаблону: что меняет, как проверялось, что не проверено.
4. В описании PR обязательно укажи, на какой территории (ОС, железо) проверялось.

## Проверки перед PR

- Windows-ветка: `ЗАПУСК.bat` хотя бы до фазы карты среды на реальной машине.
- Linux-ветка: `bash запуск.sh` до фазы выбора решения (сборка ISO не обязательна
  для мелких правок, но укажи это честно).
- Если меняешь источники/пины: проверь URL руками и укажи дату проверки.

## Чего не принимаем

- Ссылки на неофициальные зеркала дистрибутивов и «выдуманные» URL.
- Правки, ломающие режим без прав администратора.
- Обфускацию, самораспаковку, скрытую телеметрию — код должен читаться.
