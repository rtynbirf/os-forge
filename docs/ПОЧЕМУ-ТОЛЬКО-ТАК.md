# ПОЧЕМУ ТОЛЬКО ТАК — свод шрамов и решений OS-FORGE

Каждое «только так» здесь оплачено чьим-то шрамом. Это не стиль, это карта
минных полей: по-другому — нет, и вот почему.

## Источник Windows-образа

| Решение | Почему только так |
|---|---|
| Fido (pbatard) по хэш-пину коммита | Прямые ссылки Microsoft на ISO живут менее 48 часов и ротируются. Хардкод ссылки = мёртвый пункт через два дня. Fido на момент запуска resolving-ит АКТУАЛЬНУЮ официальную ссылку с серверов Microsoft. Автор — автор Rufus, скрипт читается глазами (2 функции), пин по коммиту запрещает движение ветки. |
| По-другому нет: MCT | Media Creation Tool требует интерактивного GUI — автономность ломается на первом же окне. |
| По-другому нет: eval'd зеркала | Сторонние «готовые ISO» не проходят проверку хэша и закон карты=территория. |

## Источник Linux-образа

| Решение | Почему только так |
|---|---|
| cdimage.debian.org, netinst, current + SHA256SUMS | Единственный официальный источник, где (а) рядом с образом лежат SHA256SUMS — проверка целостности, (б) начиная с Debian 12 официальные установочные образы УЖЕ содержат несвободные прошивки (Wi-Fi/GPU) — не надо охотиться за драйверами до установки. `current` = актуальное на момент запуска, как требует ТЗ. |
| По-другому нет: Ubuntu v0.1 | У Ubuntu (subiquity/autoinstall) механика автоответов отличается и требует cidata-тома/правки ядра — честный ПАССИВ до v0.2. |
| По-другому нет: минимальные сторонние сборки | Не фиксируются по хэшу, не проверяются, не воспроизводимы. |

## Внедрение ответов и драйверов (Windows)

| Решение | Почему только так |
|---|---|
| autounattend.xml в корне ISO | Это встроенный механизм установщика Windows. Ноль внешних инструментов. |
| Драйверы: папка `\Драйверы` + DriverPaths (offlineServicing) | Встроенная механика Windows Setup. Ноль DISM. |
| По-другому нет: DISM /Add-Driver | Требует прав администратора и монтирования WIM — нарушает закон нуля админа на хосте. |
| По-другому нет: $WinpeDriver$ | Недокументирован, ведёт себя по-разному между версиями — не карта, а лотерея. |

## Пересборка ISO (Windows-хост)

| Решение | Почему только так |
|---|---|
| Mount-DiskImage → копия → IMAPI2FS | Всё встроено в Windows 10/11: монтирование ISO — нативное, сборка ISO — COM IMAPI2. Ноль установок. |
| Файловая система ISO: ISO9660+Joliet+UDF (rev 102) | install.wim Windows 11 больше 4 ГБ — на чистом ISO9660 сборка молча умирает на 4 ГБ. UDF обязателен. |
| Загрузочная запись: одна, EFI (efisys.bin, Platform 0xEF) | IMAPI2 умеет РОВНО ОДНУ El Torito запись (двойную запись BIOS+UEFI он не строит физически). Современное железо = UEFI (карта это покажет), efisys.bin подписан Microsoft → SecureBoot проходит. Для legacy-BIOS — пункт oscdimg/ADK пассивен, активируется осознанно. |
| Выгрузка IStream → файл: чистый .NET (ComTypes.IStream + Marshal) | ADODB.Stream не умеет читать ИЗ IStream; внешний 7z/oscimg = внешняя зависимость. Чистый .NET = самодостаточность. |

## Пересборка ISO (Linux-хост)

| Решение | Почему только так |
|---|---|
| xorriso: extract → правка → `xorriso -as mkisofs` с isohybrid-mbr + `-partition_offset 16` + два El Torito входа (BIOS isolinux + EFI efimg) | Официальный рецепт Debian по пересборке установочных образов. `partition_offset 16` нужен, иначе EFI-загрузка гибрида ломается. xorriso — единственный инструмент, который и распаковывает, и собирает гибрид BIOS+UEFI в один проход. |
| По-другому нет: genisoimage/mkisofs | Не умеют isohybrid-гибрид и EFI-образ из коробки — получится ISO без загрузки. |
| preseed вписывается в ОБА загрузчика (isolinux.cfg И grub.cfg) | BIOS и UEFI идут разными путями установщика. Вписать только в один = половина машин останется без автоответов. |

## Протокол и кодировка

| Решение | Почему только так |
|---|---|
| Машина-слова ASCII (ACTIVE/PASS/STAGE) | cmd и PowerShell пережили десятки кодовых страниц (cp866/cp1251/UTF-8). Кириллица в машинных ключах = молчаливые несовпадения сравнения. Русский — в человеческих текстах после chcp 65001. |
| Журнал в момент такта | Память (в т.ч. память сессий ИИ) врёт задним числом. Факт фиксируется строкой в момент события. |
| Артефакт = ISO + МАНИФЕСТ.json рядом (v0.1.1) | Донор практики: H-PE11-PHOENIX (artifacts/iso_26100.1_pro_ru/MANIFEST.json + VERIFICATION.txt, Task 40: SHA256 подтверждён 3× независимо). Файл без манифеста — «где-то лежит что-то»: хэш/размер/дата/параметры обязаны лежать рядом в машинной форме. Ключи ASCII — закон машины-слова. |
| Опасные пункты пассивны | Установщик по умолчанию стирает диск целиком (WillWipeDisk) — это честно названо в шаблоне предупреждением, альтернатива (вопрос установщику) документирована рядом. Осознанная активация вместо молчаливой потери данных. |
