# Каждая АКТИВНАЯ строка = команда, вшиваемая в первый вход (FirstLogonCommands).
# В команде ЗАПРЕЩЁН символ | (грамматика каталога) и кавычки " (XML).
# Активация = убрать "# " в начале строки PASS.
# ============================================================

# ── ПУНКТ: план электропитания «Высокая производительность» ─
# ПОЧЕМУ ТОЛЬКО ТАК: GUID схемы стандартен во всех Windows 10/11 (встроенная
#   схема), powercfg — встроен. По-другому нет: сторонние твикеры — чёрные
#   ящики, не карта.
ACTIVE|power-high|class=tuning-win|powercfg /setactive 8c5e7fda-e8bf-4a96-9a85-a6e23a8c635c|встроенная схема High performance

# ── ПУНКТ: телеметрия диагностики — минимум ────────────────
# ПОЧЕМУ ТОЛЬКО ТАК: групповая политика реестра — документированный Microsoft
#   механизм; значение 0 = Diagnostic Data off (Home/Pro).
# ПО ДРУГОМУ НЕТ: «де nihil»-сборки с вырезанными компонентами ломают
#   обновления — отвергнуты законом карты=территория.
ACTIVE|telemetry-off|class=tuning-win|reg add HKLM\SOFTWARE\Policies\Microsoft\Windows\DataCollection /v AllowTelemetry /t REG_DWORD /d 0 /f|документированная политика, не вырезание компонентов

# ── ПУНКТ: гибернация выключена ────────────────────────────
# ПОЧЕМУ ТАК: hiberfil.sys занимает до 40% RAM на диске; для стационарной
#   машины гибернация не нужна. Для ноутбука — ПАССИВНИ этот пункт!
# PASS|hibernate-off|class=tuning-win|powercfg /hibernate off|пассивен по умолчанию: для ноутбука гибернация нужна — активируй на стационаре

# ── ПУНКТ: классическое контекстное меню (Win11) ───────────
# PASS|classic-menu|class=tuning-win|reg add HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32 /f /ve|пассивен: вкусовщина; активируй, если надоест «новое меню» Win11

# ── ПУНКТ: ключ активации ──────────────────────────────────
# PASS|install-key|class=tuning-win|-|ПОЧЕМУ ПАССИВЕН: закон OS-FORGE — никаких ключей в репозитории и в батнике. Ключ вводится руками после установки. Установка БЕЗ ключа допустима и описана в autounattend.
