# ── МЕХАНИКА: как драйверы попадают в ISO ──────────────────
# ПОЧЕМУ ТОЛЬКО ТАК: папка \Драйверы в корне ISO + DriverPaths в
#   autounattend (pass offlineServicing) — ВСТРОЕННАЯ механика установщика
#   Windows. Батник сам уложит в ISO всё, что лежит в папке "Драйверы"
#   рядом с ЗАПУСК.bat.
# ПО ДРУГОМУ НЕТ: DISM /Add-Driver требует прав администратора и монтирования
#   WIM (нарушает закон нуля админа); $WinpeDriver$ недокументирован и ведёт
#   себя по-разному между версиями Windows — лотерея, не карта.
#
# Практика: положи .inf-паки (распакованные) в папку "Драйверы" рядом с
# ЗАПУСК.bat — они попадут в ISO автоматически. Пусто — значит инбокс-драйверы
# установщика (их в Windows 11 большинство).

# ── ПУНКТ: Snappy Driver Installer Origin (ПОСЛЕ установки) ─
# ПОЧЕМУ ТОЛЬКО ТАК: открытое сообщество, паки отдаются по индексу, работает
#   автономно без облака. Для пост-установочной добивки недостающих драйверов.
# ПО ДРУГОМУ НЕТ: DriverPack Solution тянет рекламные обёртки; вендорские
#   установщики NVIDIA/AMD/Intel требуют GUI.
ACTIVE|sdio-postinstall|class=drivers-win|https://www.snappy-driver-installer.org/ru/download|v0.1: точка входа для шага после установки (скачать → запустить → выбрать по карте). Автоматика добычи — v0.2

# ── ПУНКТ: NVIDIA GeForce (автодобыча в ISO) ───────────────
# PASS|nvidia-auto|class=drivers-win|https://www.nvidia.com/Download/|ПОЧЕМУ ПАССИВЕН: вендорские ссылки ротируются между релизами; автоматическая добыча появится в v0.2 с фиксацией хэша каждого скачанного пака в ЖУРНАЛЕ. Пока честно пассивен.

# ── ПУНКТ: AMD Adrenalin (автодобыча в ISO) ────────────────
